```text

S = 7L-4, 5 does not divide S,
F = 7*10^L-18*10^i-25,
A = 9*7^(L-2)*S, H = 25A, X = 7*10^L/H.
```

The investigation of remaining witnesses additionally retains every
restriction in [the merged global report](../global/README.md):
`L>10,000,000`, `i>=417`, `L-i>=396`, the modulo-49 table, the five
excluded length residues, and both analytic edge inequalities. None of

In particular `H | F` is the full condition; `9S | F` is the sum condition.
The letter `H` here is a divisor, not the Evertse height.

## An adjustable, exact quotient split

Write `m=(L+1)/2` and `K_t=10^t/25`. Let `t` be **any integer** satisfying

```text
m <= t <= L-1,       18*10^(t-1)+25 < H.             (1)
```

Then every full witness has one of the following forms:

```text
i < t:    q = floor(X),
i >= t:   q = (-A^(-1) mod K_t), interpreted in [0,K_t).
```

It must still pass the recovered-position restrictions and the full
identity `Hq=F`. The possible split `t=m` always exists by the corrected
bound (4) of [TWO_QUOTIENTS.md](../global/TWO_QUOTIENTS.md). Indeed that
bound applies to the largest low position `i=m-1` whether or not this
position is `3 mod 6`: its size proof uses only `i<=m-1`.

**Proof.** For `i<t`, equation (1) gives
`0<X-q=(18*10^i+25)/H<1`, so the integer `q` equals `floor(X)`.
For `i>=t`, the exact identity

```text
Aq+1 = (10^i/25)*(7*10^(L-i)-18)
```

implies `Aq+1=0 mod K_t`. The inherited domain gives `gcd(A,10)=1`.
Also `0<q<X<K_m<=K_t` by the corrected exact bound
`X/K_m=49/(9S)*(10/49)^((L-1)/2)<1`. Thus there is only one inverse
representative available. This proves both branches, including the case
`t=L-1`, when the high branch is empty because `i<=L-2`.

There is an exact largest usable split

```text
t_* = max { t in Z : m<=t<=L-1 and 18*10^(t-1)+25<H }.
```

It can be found by integer comparisons, without approximate logarithms.
For sufficiently large `L` the cap `L-1` is inactive, and

```text
t_* = (log 7/log 10)*L + (log L/log 10) + O(1).
```

This last formula describes the split's size, not a bound on any solution;
the definition by integer comparisons is what is used. The constants
implicit here are absolute: `H=225*7^(L-2)*(7L-4)`, so
`log H=L log 7+log L+O(1)`. The first branch therefore extends well beyond
the original half-length split. This does not eliminate the high branch.

There is also a precise interpretation as inverse lifting. If
`q_t=(-A^(-1) mod K_t)` and `q_m=(-A^(-1) mod K_m)`, then
`q_t=q_m+j*K_m` for a nonnegative integer `j`. Since `X<K_m`, a necessary
condition for `q_t<X` is `j=0`, or equivalently

```text
A*q_m+1 = 0 (mod K_t).
```

When this holds, `q_t=q_m`, and the original size check `q_m<X` remains
necessary. It is not proved that the lift must change at some level
`t<=t_*` for every remaining length. Merely observing that `K_t/X` is
large would not prove that.

## Exact interaction with the varying digit sum

Put `R_L=(10^L-1)/9`, an integer, and define

```text
d = ord_S(10),
u = (7*R_L-2)*2^(-1) mod S.
```

The domain makes `S` odd and coprime to 10, so both the inverse of 2 and
the multiplicative order `d` exist. We have `1<=d<=phi(S)<=S-1`.
The **full** digit-sum condition is exactly

```text
S | n  <=>  9S | F  <=>  10^i = u (mod S).          (2)
```

To verify this without cancelling a nonunit modulo `9S`, use the integer
identity `n=7R_L-2-2*10^i` and invert only 2 modulo the odd number `S`.
This argument is valid even when `3 | S`.

If `u` does not belong to the cyclic subgroup generated by 10 modulo
`S`, no position satisfies (2). This includes the case `gcd(u,S)>1`.
Otherwise there is a unique class `r_S mod d` satisfying (2), because
`10^a=10^b mod S` exactly when `a=b mod d`.

For any specified integer `k>=1`, let `r_k` be the unique exponent class
modulo `T_k=6*7^(k-1)` supplied by the primitive-root theorem:

```text
18*10^r_k = 7*10^L-25 (mod 7^k).
```

Then the unrestricted congruence system

```text
7^k | F(L,i),  S | n(L,i)
```

has a nonnegative integer solution `i`, with the upper position bound
dropped, if and only if `r_S` exists and

```text
r_k = r_S (mod gcd(T_k,d)).                         (3)
```

When compatible, its solutions form one class modulo `lcm(T_k,d)`.
This is the ordinary generalized Chinese remainder theorem, applied to
the two exponent classes; it does not require the moduli to be coprime.

Write `e=v_7(d)`. The compatibility modulus is exactly

```text
gcd(T_k,d)=gcd(6,d)*7^min(k-1,e).
```

For each **fixed** length it stabilizes once `k>=e+1`, and
`e<=floor(log(S-1)/log 7)`. In particular it has already stabilized at
`k=L-2`: `7^(L-3)>7L-4` for `L>=5`, as follows from `49>31` and induction.
No uniformity in `L` is claimed for `d,u,r_S`, which all depend on `L`.

Crucially, CRT compatibility is **not** bounded-position existence.
At `k=L-2`, `T_k>L-1`, so at most one original position survives the
seven-power congruence: the least nonnegative `r_k`, and only if `r_k<L`.
It must additionally satisfy `r_k=r_S mod d` and every inherited position
restriction. Equation (3) may instead have its least compatible position
far above `L`. Conversely, the small modulus in (3) does not show that
`r_k<L` is impossible. Its stabilization is not a proof that the full
digit sum ceases to add information as `k` increases.

## Attempts and their exact obstructions

1. **Remainder lower bound for `q_1`.** The desired identity is
   `7*10^L-H*floor(X)=18*10^i+25`. Extending the low branch to `i<t_*`
   does not prohibit it. The first unproved step is a uniform exclusion
   of this particular remainder shape, or a sufficiently strong explicit
   lower bound for the positive fractional part of
   `X=343*(10/7)^L/(225*(7L-4))`. The elementary bound for a nonzero
   rational fractional part is only `1/H`, which is too small.
2. **Large inverse modulus for `q_2`.** Enlarging to `K_(t_*)` makes the
   necessary unchanged-lift condition stronger, but the first unproved
   step is that every residual length either changes the inverse lift,
   fails `q<X`, or fails the recovered valuations/full equality. An
   inverse representative need not have size comparable to its modulus.
3. **Digit-sum congruence plus seven-power congruence.** The exact exponent
   CRT above is applicable and fully effective at any specified length.
   The first unproved step is showing, uniformly in length, that its
   bounded representative cannot satisfy all the residual restrictions.
   The varying order `d` and target `u` have not been eliminated. A
   positive compatibility result with unrestricted `i` would be
   insufficient as well.
4. **Introduce the exact quotient as an auxiliary logarithm base.** The
   available inequality is only `q<X`, permitting `log q` of order
   `L*log(10/7)`. It supplies no fixed-height base. An estimate with
   constants treating this `q`, or `S=7L-4`, as fixed would be inapplicable
   to the uniform question. No applicable theorem with sufficient
   uniform constants was obtained by this reduction.

The fixed-modulus obstruction in PR #9 concerns an **existential modular
quotient**. It does not, by itself, prove that every conceivable finite
congruence argument about the particular functions `q_1(L),q_2(L)` fails.
The limitation claimed here is the specific unresolved step in each
attempt, not impossibility of all future quotient methods.
